# IDTs for Huawei H-Log

The following IDTs are recommended for use with Huawei H-Log:

- **CSC.Huawei.H-Log_to_ACES.ctl** – maps from Huawei H-Log to ACES AP0 
- **CSC.Huawei.ACES_to_H-Log.ctl** – maps from ACES AP0 to Huawei H-Log 

These transforms are derived from the H-Log technical specification and are the recommended IDTs for all H-Log workflows.
